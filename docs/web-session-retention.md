# 웹 로그인 유지

2026-11-13: 브라우저 종료/OS 메모리 회수 후에도 로그인 복원.

- HttpOnly + Secure + SameSite=Strict 쿠키, Max-Age 86400초.
- 인증 갱신 성공 시 쿠키 및 서버 유휴 만료를 24시간으로 갱신.
- JS에는 브라우저 ID/proof만 localStorage로 보관. 이전 sessionStorage 정보는 인증 성공 시 이전.
- 로그아웃 시 서버 세션 및 로컬 복원 정보를 삭제. 쿠키 삭제는 Max-Age=0.
- Safari에서 사이트 데이터를 직접 삭제하거나 비공개 모드 저장소가 폐기되면 다시 로그인해야 함.
- 네이티브 앱: 30분 액세스 토큰, 90일 유휴 만료. 절대 만료 없음(NULL). 기존 native 세션에도 동일 적용.
