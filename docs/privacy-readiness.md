## 현재 구현과 사실 확인

- 이메일 가입: 이름, 이메일, 비밀번호 해시, 인증 정보. 비밀번호 원문은 보관하지 않습니다.
- 소셜 가입: 제공자·계정 식별자, 이름·이메일, 제공되는 프로필 사진 URL. 이미 있는 프로필 사진은 추가 연결로 교체하지 않습니다.
- 동기화: 문서, 생각, 메모상자, 배치, 변경 이력, 선택적으로 첨부한 사진·음성·위치 정보.
- 공유 공간: 참여자에게 이름·이메일, 공유 자료, 작성자·수정 이력이 표시됩니다.
- 인증메일 발송: 현재 다음 SMTP(smtp.daum.net). 실제 위탁 계약·처리 위치·제공자 보관 조건은 별도 확인이 필요합니다.
- 외부 로그인 SDK, 소셜 프로필 이미지, 글로벌 지도 타일은 외부 서버 요청을 발생시킬 수 있습니다. 공급자·요청 정보·국가·보관 조건을 확인해야 합니다.
- Cloudflare와 유료 결제는 운영자가 도입 예정이라고 확인했습니다. 현재 계약·수탁사로 임의 기재하지 않습니다.

## 탈퇴 처리

환경설정의 오픈소스 정보 아래 회원탈퇴 → 삭제 범위 확인 → 소유 공간별 이전/삭제 선택 → 공유 자료 삭제 개별 동의 → 이메일 코드 확인 → 최종 확인.

- 현재 별도 법정 보관 정보는 없다는 운영자 지시에 따라 운영 DB의 계정·인증·소셜 연결·가입 인증·개인 자료를 삭제합니다.
- 이전하지 않고 삭제에 동의한 소유 워크스페이스는 다른 참여자의 글까지 모두 삭제합니다.
- 이전한 공간은 기존 ID와 자료를 유지하고 소유자만 변경합니다. 수신자의 기존 공간을 덮어쓰지 않습니다.
- 다른 사람 소유의 공동 작성물은 유지하며 작성자 계정 참조는 NULL 처리합니다. 사용자가 본문에 직접 입력한 개인정보까지 자동 익명화한다는 의미는 아닙니다.
- 사진·음성·프로필 파일은 즉시 삭제를 시도합니다. 실패한 파일 작업은 개인정보 내용 없이 리소스 UUID·종류만 저장한 내구성 큐에서 재시도하고 성공하면 큐 항목을 삭제합니다.
- 해당 기기의 계정별 캐시와 미동기화 자료도 삭제합니다. 실패하면 재실행 때 재시도합니다. 다른 기기의 오프라인 사본을 서버가 원격으로 지울 수 있다고 보장하지 않습니다.
- 모든 위버 세션과 소셜 연결 레코드를 삭제합니다. Google·카카오 등의 서비스 계정 자체를 삭제하지 않습니다. 외부 제공자 측 앱 권한 철회는 별개이며 현재 모든 제공자에 대한 원격 철회를 구현한 것은 아닙니다.
- 기존 이메일 기반 WEAVER_TEST_DATA 및 미완료 OAuth 흐름도 제거하여 재가입 시 자료가 살아나지 않도록 합니다.

## 백업: 현재 미운영, 도입 시 최대 30일

운영자가 2026-11-12 현재 테스트 서버에는 DB 백업이 없다고 확인했습니다. 현재 탈퇴 처리는 운영 DB 즉시 삭제이며, 백업을 의무적으로 생성하거나 30일 보관하지 않습니다.
향후 개인정보 백업 도입 시 보관 상한은 최대 30일입니다. 자동 만료와 복원 후 탈퇴 자료 재삭제 절차를 함께 구현해야 합니다. 현재 존재하지 않는 백업의 자동 삭제·복원 절차가 구현되었다는 의미는 아닙니다.
확인한 서버 예약 작업에서 개인정보 백업 작업은 발견되지 않았고 `.weaver-backup-*`는 웹 배포 산출물입니다. 첨부파일·외부 호스팅 백업을 추후 도입하면 동일 정책을 적용해야 합니다.

## 가입 동의와 방침

개인정보처리방침 공개와 수집·이용 동의는 별개입니다. 서비스 계약 이행에 필요한 처리는 그 법적 근거를 검토하고, 모든 항목을 한 개의 ‘방침 동의’ 체크박스로 포괄하지 않습니다.
동의를 근거로 처리하는 항목은 목적·항목·보유기간·거부권 및 불이익을 고지하고 필수/선택을 분리합니다. 사전 체크하지 않으며 서버에서도 동의 버전·시각·항목을 검증·기록해야 합니다.
소셜로 처음 가입하는 이용자도 동일한 안내를 받을 수 있어야 합니다. 마케팅 수신 동의는 선택 항목으로 분리합니다.

위탁은 서비스 운영을 위해 지시에 따라 처리하는 경우이고, 제3자 제공은 수령자가 자기 목적에 이용하는 경우입니다. 같은 ‘외부 업체’라는 이유로 동일한 동의가 필요한 것은 아닙니다.
국외 이전은 별도 법적 근거와 고지 항목을 확인해야 합니다. 계약 이행에 필요한 처리위탁·보관에서 방침 공개 또는 통지가 인정되는 경우가 있으나, 모든 CDN·분석·제3자 제공에 자동 적용되지는 않습니다.
Cloudflare 도입 전 제품 종류(DNS만/CDN 프록시/Workers/스토리지), 실제 전송 항목, 해외 원격 접근, 수탁자·재수탁자 및 처리 국가를 확정하세요.
